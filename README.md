# منصة وسطاء إزدان

منصة ويب لبرنامج الوسطاء العقاريين لدى إزدان. يسجّل فيها الوسيط المرخّص، ويسوّق مشاريع إزدان، ويحمي عملاءه، ويتابع عمولته من الحجز حتى الصرف. ولفريق إزدان لوحة إدارة لمراجعة الوسطاء واعتماد الحجوزات والمبيعات وصرف العمولات.

الواجهة عربية من اليمين لليسار، وتتبع هوية إزدان البصرية: الألوان (زيتوني، نحاسي، كريمي)، وخط Doran للعناوين، وHT Rakik للمحتوى، والشعار الأصلي.

## ما تقدمه المنصة

### للوسيط
- **التسجيل والانضمام:** نوع الحساب (فرد أو منشأة)، رخصة فال وتاريخ انتهائها، والوثائق (الهوية، رخصة فال، الآيبان، السجل التجاري). ثم مراجعة إزدان، ثم توقيع إلكتروني لاتفاقية الوساطة يفعّل الحساب.
- **حماية العميل:** يُقفل رقم جوال العميل باسم أول وسيط يسجله طوال مدة الحماية (60 يومًا افتراضيًا). يُرفض تسجيله لأي وسيط آخر حتى ولو حاولا التسجيل في نفس اللحظة. وعند اعتماد الحجز تمتد الحماية حتى إغلاق الصفقة.
- **إدارة العملاء:** مراحل العميل (جديد، تم التواصل، مؤهل، معاينة، ثم الحجز والبيع اللذان تعتمدهما الإدارة)، وسجل متابعة، ومواعيد متابعة، وتنبيه بانتهاء الحماية.
- **المشاريع والوحدات:** مخزون حي لكل وحدة بحالتها وسعرها ومساحتها، مع العمولة المتوقعة لكل وحدة، ونص تسويقي جاهز يتضمن رقم رخصة فال ورقم ترخيص الإعلان.
- **طلب الحجز:** يختار الوسيط وحدة متاحة لعميله ويرسل الطلب.
- **كشف العمولات:** حالة كل عمولة (متوقعة، ثم معتمدة، ثم مصروفة) مع رقم الحوالة، وضريبة القيمة المضافة 15% للوسيط المسجل ضريبيًا.
- **الفئات:** برونزي، ثم فضي من 3 صفقات (+0.25%)، ثم ذهبي من 10 صفقات (+0.5%).

### لفريق إزدان
- مراجعة طلبات الانضمام: اعتماد الوثائق، أو طلب تعديل مع ملاحظة، أو إيقاف الحساب أو إعادة تفعيله.
- **الحجوزات:** تأكيد الحجز يقفل الوحدة، ولا يمكن حجز وحدة مرتين. بعدها تسجيل البيع بالقيمة النهائية فتُحتسب العمولة وتُعتمد تلقائيًا، ثم تسجيل الصرف برقم الحوالة. ويمكن رفض الطلب أو إلغاء الحجز.
- إدارة المشاريع وبياناتها النظامية (ترخيص الإعلان، ترخيص وافي)، وإضافة وحدات دفعة واحدة بلصقها من Excel.
- إسناد عميل من الشركة إلى وسيط، مع احترام حماية الوسطاء الآخرين.
- لوحة مؤشرات، وسجل تدقيق لكل إجراء، وإعدادات البرنامج، وإضافة مديرين.

## قواعد مهمة مطبّقة في الخادم
- كل إجراء يتحقق من الصلاحية في الخادم: لا يرى الوسيط عملاء غيره ولا وثائقهم، ولا يصل إلى لوحة الإدارة.
- الوثائق تُحفظ خارج المجلد العام، ولا يفتحها إلا صاحبها أو الإدارة. ويُتحقق من نوع الملف من محتواه الفعلي (PDF أو JPG أو PNG فقط، حتى 5 ميجابايت).
- التحقق من رقم الجوال السعودي، ومن الآيبان بخوارزمية mod-97، ومن الرقم الضريبي والسجل التجاري، ومن سريان رخصة فال.
- لا يستطيع الوسيط نقل عميله إلى مرحلة «محجوز» أو «تم البيع» بنفسه.
- كلمات المرور مشفّرة بـ bcrypt، والجلسات في كوكي HttpOnly موقّع، ومحاولات الدخول محدودة.

## التشغيل محليًا

المتطلبات: Node.js 20 أو أحدث.

```bash
npm install
cp .env.example .env        # ثم عدّل SESSION_SECRET وADMIN_PHONE وADMIN_PASSWORD
npm run setup               # ينزّل خطوط الهوية، ينشئ قاعدة البيانات، ينشئ حساب المدير ومشاريع تجريبية
npm run dev                 # http://localhost:3000
```

- يدخل المدير برقم الجوال وكلمة المرور الموجودين في `.env`.
- ينشئ الوسطاء حساباتهم من صفحة «انضم كوسيط».
- لإيقاف المشاريع التجريبية اجعل `SEED_DEMO="0"` قبل `npm run setup`، أو احذفها من لوحة الإدارة.

أوامر أخرى:

| الأمر | الوظيفة |
|---|---|
| `npm run build && npm start` | تشغيل نسخة الإنتاج |
| `npm test` | اختبارات قواعد العمل (العمولة، الفئات، الجوال، الآيبان، الحماية) |
| `npm run lint` | فحص الأنواع (TypeScript) |
| `npm run fonts` | تنزيل خطوط الهوية من مجلد Google Drive |

## الخطوط
خطوط Doran وHT Rakik و29LT Zarid مرخّصة تجاريًا، ولذلك **لا تُرفع إلى هذا المستودع العام**. يجلبها أمر `npm run fonts` من مجلد الهوية في Google Drive إلى `public/fonts`. إن لم تتوفر الخطوط تعمل المنصة بخطوط بديلة. وتأكد من أن ترخيص الخطوط يسمح باستخدامها على الويب.

## النشر للإنتاج
1. **قاعدة البيانات:** غيّر `provider` في `prisma/schema.prisma` إلى `"postgresql"` وضع رابط PostgreSQL في `DATABASE_URL`، ثم نفّذ `npx prisma db push` و`npm run db:seed`.
2. **الوثائق:** اجعل `UPLOAD_DIR` مجلدًا دائمًا على الخادم وخذ له نسخًا احتياطية. وعند النشر على منصة بلا قرص دائم (مثل Vercel) يلزم نقل التخزين إلى خدمة تخزين سحابية خاصة، والتعديل يكون في `src/lib/uploads.ts` فقط.
3. **المتغيرات:** `SESSION_SECRET` عشوائي بطول 48 حرفًا على الأقل، وكلمة مرور قوية للمدير.
4. يناسبها أي خادم Node.js، مثل Railway أو Render أو خادم سحابي محلي، مع شهادة HTTPS.

## البنية التقنية
Next.js 15 (App Router وServer Actions) وTypeScript وPrisma (SQLite للتطوير، وPostgreSQL للإنتاج)، مع jose للجلسات وbcryptjs لكلمات المرور. ولا توجد مكتبات واجهة خارجية: التصميم مبني بـ CSS على رموز الهوية في `src/app/globals.css`.

```
prisma/schema.prisma      نموذج البيانات
src/lib/                  قواعد العمل، الجلسات، الرفع، التنسيق
src/app/(auth)/           الدخول والتسجيل
src/app/broker/           بوابة الوسيط
src/app/admin/            لوحة الإدارة
src/app/api/files/        عرض الوثائق المحمي
```
